# ☀️ Summer Development Research: Seattle Eastside

An interactive, data-driven dashboard curated for a **rising 7th-grade student**. This application synthesizes research on high-engagement summer programs in the Seattle Eastside area (**Redmond, Bellevue, and Bothell**), specifically targeting coding, math, engineering, and physical logic.

## 🚀 Live Application
[View the Interactive Dashboard](https://gauravbi.github.io/summer-research/)

---

## 🎯 The Research Objective
This project identifies summer programs that provide "hands-on" engagement for a high-performing student with strengths in math, science, and creative arts. The goal was to find programs that:

*   **Encourage Engagement:** Hands-on activities to maintain focus and excitement.
*   **Balance Modalities:** A mix of self-study (prep) and peer collaboration.
*   **Leverage Strengths:** Utilize high mathematical and comprehension abilities.
*   **Prefer Local:** Focus on Seattle Eastside in-person experiences with specific hybrid options.

### Student Profile
*   **Grade:** Rising 7th (Middle School).
*   **Primary Strengths:** Mathematics, Science, Reading Comprehension, Creativity.
*   **Working Style:** High effort, highly motivated, requires active participation.

---

## 🛠️ Dashboard Features
*   **Program Explorer:** A filterable interface to browse programs by category (Coding, Math, Science, Physical).
*   **Profile Alignment Map:** A dynamic **Radar Chart (Chart.js)** that visualizes how each program balances specific engagement metrics like "Math/Logic" vs "Hands-on Activity."
*   **Synthesis & Analysis:** Each program includes a "Why It Fits" section explaining its relevance to the student's specific profile.
*   **Modern UI:** Built with a professional, warm-neutral aesthetic using **Tailwind CSS**.
